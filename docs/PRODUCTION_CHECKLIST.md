# PRODUCTION_CHECKLIST — قائمة ما قبل الإطلاق

راجع كل بند **على بيئة الإنتاج نفسها**، لا على staging ولا محلياً.
البنود المعلّمة 🔴 **حاجبة**: لا تُطلق قبل اجتيازها.

---

## 1. النطاق و HTTPS

- [ ] 🔴 النطاق الأساسي يفتح ويعرض الصفحة الرئيسية
- [ ] 🔴 النطاق الثاني (`www` أو الجذري) يُحوَّل إلى الأساسي بـ 308
- [ ] 🔴 `http://` يُحوَّل تلقائياً إلى `https://`
- [ ] 🔴 الشهادة صالحة بلا تحذير في المتصفح
- [ ] رأس `Strict-Transport-Security` موجود
- [ ] لا حلقة تحويل (افتح النطاقين وتابع سلسلة التحويل)

```bash
curl -sI https://www.example.com | grep -i strict-transport
curl -sI http://example.com | grep -i location
```

## 2. متغيرات البيئة

- [ ] 🔴 `APP_ENV=production` (وليس `staging` سهواً)
- [ ] 🔴 `SESSION_SECRET` مُولَّد عشوائياً ومختلف عن كل بيئة أخرى
- [ ] 🔴 `NEXT_PUBLIC_APP_URL` يطابق النطاق الفعلي بـ HTTPS
- [ ] 🔴 `DATABASE_URL` يشير لقاعدة الإنتاج مع `sslmode=require`
- [ ] `CANONICAL_HOST_MODE` يوافق `NEXT_PUBLIC_APP_URL`
- [ ] `ANTHROPIC_API_KEY` مضبوط
- [ ] `LOG_LEVEL=info`
- [ ] 🔴 لا ملف `.env` مُودَع في Git

```bash
git ls-files .env    # يجب ألّا يُخرج شيئاً
```

```bash

```

## 16. بعد الإطلاق

**اليوم الأول:** راقب `/api/health` كل ساعة · راجع السجلات بحثاً عن
`level:error` · تابع التكلفة في `/admin/analytics`.

**الأسبوع الأول:** راجع معدّل إكمال المقابلة (< 50٪ يعني مشكلة في الأسئلة) ·
راجع التخلّي حسب الخطوة لكشف «السؤال القاتل» · راجع التقييمات 👎 · راجع
التكلفة لكل معروض.

**شهرياً:** `npm audit` · اختبر الاسترجاع · راجع سجل التدقيق · راجع الحسابات
ذات الصلاحيات الإدارية.

## 17. حالة المشروع اليوم — ما لم يُنفَّذ

بنود خارج نطاق v1 عمداً، مذكورة هنا حتى لا تُكتشف بعد الإطلاق:

| البند | الحالة |
|---|---|
| بوابة الدفع | غير مُنفَّذة — البنية جاهزة لإضافتها |
| فرض الحصة الشهرية لكل خطة | غير مُنفَّذ — الرصيد يعمل لكن `lettersPerMonth` غير مفروض |
| إرسال البريد الفعلي | غير مُنفَّذ — روابط الاستعادة تُطبع في السجل |
| رفع المرفقات | غير مُفعَّل — طبقة التخزين جاهزة |
| اختبارات E2E | غير مكتوبة — التغطية وحدة + تكامل (91 اختباراً) |
| تحديد المعدّل عبر Redis | في الذاكرة — لا يكفي لنشر متعدد النسخ |

> **تحديد المعدّل** أهمها عملياً: مع أكثر من نسخة يصبح الحد لكل نسخة لا
> لكل مستخدم. راجع [SECURITY.md §5](SECURITY.md) و[DECISIONS.md #D-017](DECISIONS.md).
